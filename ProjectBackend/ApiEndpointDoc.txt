http://127.0.0.1:8000/api/model/deserial/objectId

PUT
http://127.0.0.1:8000/api/model/deserial/objectId
DELETE
http://127.0.0.1:8000/api/model/deserial/objectId

To POST and PUT using Postman, you have to make use of the option of Body, under where you enter the API ENDPOINT URL
There you use a json object as input.
Example:
POST USER
Body:
{
    "password": "adassfsafasdsads",
    "last_login": null,
    "is_superuser": false,
    "username": "NewUser",
    "first_name": "",
    "last_name": "fasfsa",
    "email": "",
    "is_staff": false,
    "is_active": true,
    "date_joined": "2024-08-31T10:20:03.876952Z",
    "groups": [],
    "user_permissions": []
}

The above is a json object in its simplest form
