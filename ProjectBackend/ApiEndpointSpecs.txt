API ENDPOINT SPECIFICS
To get all the objects from a database table in json format:
api/model/serial

to GET specific object from a database table - need primarykey or id or any field in the object
api/model/deserial/primarykeyNum

to POST specific object from a database table - no need for a id or primaryKey
api/model/deserial

to PUT/UPDATE specific object from a database table - need an id or primaryKey for identification of object, then the specifics of what needs to be updated
api/model/deserial/primarykeyNum

to DELETE specific object from a database table - need only primary key or id
api/model/deserial/primarykeyNum
